# Доска для занятий

Онлайн-доска для занятий математикой и физикой вдвоём. Работает в браузере, без регистрации и серверов: рисунки хранятся у каждого участника и передаются напрямую между ними.

**Открыть:** https://miroslava553.github.io/doska/

- `index.html` — сама доска (один файл);
- `version.json` — номер версии: открытая доска сравнивает его со своим и предлагает обновиться;
- `source/` — исходный код (сборка: `npm install`, затем `node build.mjs`).
